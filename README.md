# TemplateFiller — набивалка шаблонов

Небольшое приложение на ASP.NET Core для создания, форматирования и заполнения текстовых шаблонов.

## Возможности

- простой интерфейс со списком шаблонов;
- визуальный редактор в стиле мини-Word;
- PT Astra Serif, 12 pt для документа и печати;
- кнопка «Вставить поле»;
- преобразование последовательностей из трёх и более подчёркиваний в безымянные поля;
- сохранение прочерков в строке ручной даты вида `____ . ____ . 2026 год`;
- заполненное поле занимает ровно ширину введённого текста;
- печать и сохранение в PDF через браузер;
- локальное JSON-хранилище без отдельной БД.

## Автоматический деплой

Проект готов к загрузке в GitHub. Workflow `.github/workflows/deploy.yml` запускается при каждом push в `main` и вручную через `workflow_dispatch`.

Нужны три GitHub Actions secret:

```text
VPS_HOST
VPS_USER
VPS_SSH_KEY
```

Production URL:

```text
https://annushkaaaaa.store/templates/
```

Подробности находятся в `deploy/FIRST_DEPLOY.md`.

## Локальный запуск

```bash
dotnet run
```

Открыть:

```text
http://localhost:5080
```

Либо через Docker:

```bash
docker compose up -d --build
```
