# TemplateFiller — набивалка шаблонов

Небольшое приложение на ASP.NET Core для создания, заполнения и выгрузки текстовых шаблонов.

## Возможности

- визуальный редактор в стиле мини-Word;
- PT Astra Serif, 12 pt для документа, печати и Word;
- кнопка «Вставить поле»;
- преобразование последовательностей из трёх и более подчёркиваний в безымянные поля;
- сохранение прочерков в строке ручной даты вида `____ . ____ . 2026 год`;
- редактирование обычного текста прямо в режиме заполнения;
- сохранение правок шаблона из режима заполнения без записи введённых значений полей в сам шаблон;
- экспорт заполненного документа в `.docx`;
- печать и сохранение в PDF через браузер;
- SQLite-база для шаблонов и пользователей;
- cookie-авторизация;
- автоматический импорт старого `App_Data/templates.json` в SQLite при первом запуске.
- загрузка собственных TTF, OTF, WOFF и WOFF2-шрифтов в SQLite;
- использование загруженных шрифтов в многостраничных рукописных конспектах.

## Первоначальный пользователь

```text
Логин: 01
Пароль: pswd01
```

Пароль можно сменить после входа через меню пользователя.

## Где хранятся данные

В контейнере база находится здесь:

```text
/app/App_Data/template-filler.db
```

На VPS каталог контейнера смонтирован в:

```text
/home/deploy/apps/template-filler/data
```

То есть фактический файл на VPS:

```text
/home/deploy/apps/template-filler/data/template-filler.db
```

Каталог `data` не удаляется при деплое.

## Автоматический деплой

Workflow `.github/workflows/deploy.yml` запускается при push в `main` и вручную через `workflow_dispatch`.

Нужны GitHub Actions secrets:

```text
VPS_HOST
VPS_USER
VPS_SSH_KEY
```

Production URL:

```text
https://annushkaaaaa.store/templates/
```

Перед первым деплоем должен быть поднят общий reverse proxy и создана Docker-сеть `shared-proxy`.

## Локальный запуск

```bash
dotnet run
```

Открыть:

```text
http://localhost:5080
```

Либо через Docker:

```bash
docker compose up -d --build
```

## Начальный вход

```text
Логин: 01
Пароль: pswd01
```

Начальная учётная запись открывает приложение сразу. Пароль можно изменить в меню пользователя.
При обновлении со старой версии одноразовая миграция восстанавливает начальный вход и не повторяется после последующих перезапусков.



## Рукописные конспекты

После входа откройте раздел **«Рукописные конспекты»** в боковом меню или страницу `handwriting.html`.

В модуле доступны:

- семь естественных пресетов связного и повседневного почерка;
- тетрадь в линейку, клетку, белый и кремовый лист;
- синяя, тёмно-синяя, чёрная и бледная шариковая ручка;
- автоматическое разбиение большого текста на страницы A4;
- сохранение одной страницы в PNG;
- выгрузка всех страниц одним ZIP-архивом;
- печать и сохранение многостраничного PDF средствами браузера.

Настройки и последний введённый текст сохраняются локально в браузере.

## Собственные рукописные шрифты

В разделе «Рукописные конспекты» можно загрузить собственный файл шрифта в формате TTF, OTF, WOFF или WOFF2 размером до 8 МБ. Файл сохраняется в SQLite и после авторизации доступен с других устройств. Для каждого пользователя хранится отдельный список шрифтов. Загруженный шрифт появляется в группе «Мои шрифты» и сразу может использоваться для многостраничного конспекта.
