# TemplateFiller v7

1. Замени содержимое репозитория файлами из этого архива.
2. Не удаляй серверный каталог `/home/deploy/apps/template-filler/data` — там хранится SQLite-база.
3. Сделай push в `main`.
4. Открой `https://annushkaaaaa.store/templates/`.
5. Войди:

```text
01
pswd01
```

6. После входа пароль можно сменить в меню пользователя.

Если ранее использовался `templates.json`, приложение автоматически импортирует его содержимое в SQLite и переименует файл в `templates.json.migrated`.


После деплоя раздел доступен по адресу `https://annushkaaaaa.store/templates/handwriting.html`.

### Загрузка собственных шрифтов

Откройте «Рукописные конспекты» → блок «Собственные шрифты». Поддерживаются `.ttf`, `.otf`, `.woff`, `.woff2`, максимальный размер — 8 МБ. Шрифты хранятся в том же постоянном файле SQLite, что и шаблоны.
