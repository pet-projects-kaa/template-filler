# Document Studio v14

Исправлено:
- пакетная загрузка шрифтов выполняется по одному файлу из выбранной пачки и не упирается в общий размер multipart-запроса;
- увеличен серверный лимит multipart до 250 МБ;
- загруженные шрифты регистрируются через FontFace API;
- карточка шрифта использует внутреннее имя AssetFont_<id>, а не имя файла;
- экспорт рукописи ожидает фактическую загрузку выбранного шрифта.
