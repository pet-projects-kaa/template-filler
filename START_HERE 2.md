# TemplateFiller v5

1. Замени содержимое репозитория файлами из этого архива.
2. Не удаляй серверный каталог `/home/deploy/apps/template-filler/data` — там хранится SQLite-база.
3. Сделай push в `main`.
4. Открой `https://annushkaaaaa.store/templates/`.
5. Войди:

```text
01
pswd01
```

6. Сразу задай новый пароль. Первоначальный пароль нельзя оставить после первого входа.

Если ранее использовался `templates.json`, приложение автоматически импортирует его содержимое в SQLite и переименует файл в `templates.json.migrated`.
